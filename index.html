🦈 Baby Shark: Python Block Builder

Build a real Python program by ordering blocks and setting indentation. Then test your logic!

1. Block Bank

Click a block to add it to your program. Every block is needed. The bank is intentionally shuffled.

Tip: Function bodies need one indentation level. The loop body needs two.

2. Your Program

Select a block, then use ↑ ↓ and ← → to change its position or indentation. Drag-and-drop also works on desktop.

Start by adding a block from the bank.

3. Python Preview

This updates as you arrange the blocks.

4. Program Output
The simulation runs only after the code matches the target program. It does not execute arbitrary Python.
Complete and check your program to see its output.
Learning goal: Identify constants, function definitions, function calls, loops, indentation, and the Python main guard. The checker validates exact block order and indentation for the supplied reference solution.
